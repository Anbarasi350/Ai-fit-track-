# Phase 1 — Brainstorming & Ideation

## Project Title
AI FitTrack

## Problem Statement
Many beginners find it difficult to decide how to start a consistent fitness routine. They may have basic information about their body measurements and habits but do not know how to convert those inputs into a simple starting plan.

## Proposed Solution
AI FitTrack accepts basic lifestyle inputs, calculates BMI and uses a small KNN machine-learning model to classify the user's broad fitness focus. The system then presents simple recommendations and a 7-day starter plan.

## Target Users
- College students
- Fitness beginners
- Users who want a simple habit-planning dashboard

## Expected Outcome
A beginner-friendly web application that demonstrates an end-to-end AI/ML workflow from user input to prediction and recommendation.
