# AI FitTrack — Project Report

## Abstract

AI FitTrack is an educational AI/ML web application designed to help beginners organize a simple fitness starting plan. The application accepts basic lifestyle inputs, calculates BMI and applies a K-Nearest Neighbors classifier to suggest a broad fitness focus. It then generates simple recommendations and a 7-day starter plan.

## Introduction

Fitness planning can be confusing for beginners because different users have different activity levels, sleep patterns and body measurements. AI FitTrack demonstrates how structured inputs can be processed by an ML model and converted into an understandable output.

## Objectives

- Build a simple AI/ML application.
- Demonstrate data preprocessing.
- Demonstrate a KNN classification workflow.
- Calculate BMI from height and weight.
- Produce an easy-to-understand fitness focus.
- Present a simple weekly starter plan.

## Methodology

1. Generate reproducible synthetic training data.
2. Create a target label using simple rules.
3. Prepare six numerical features.
4. Standardize features using StandardScaler.
5. Train a KNN classifier.
6. Accept user input through Streamlit.
7. Predict a fitness focus.
8. Display recommendations and a 7-day plan.

## Advantages

- Simple interface
- Easy to demonstrate
- No paid API
- Reproducible
- Clear ML workflow

## Limitations

- Synthetic training data
- Simplified target labels
- Not clinically validated
- Not a substitute for a doctor, dietitian or qualified fitness professional

## Future Enhancements

- Train on a carefully curated real-world dataset.
- Add user history and progress charts.
- Add explainable-ML visualizations.
- Add exercise-library filtering.
- Add optional wearable-data integration.
- Evaluate the model using a held-out test dataset.

## Conclusion

AI FitTrack demonstrates a complete beginner-friendly AI/ML project pipeline from user input to preprocessing, prediction and recommendation. It is intended as an academic demonstration rather than a medical application.
