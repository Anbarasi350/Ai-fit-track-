# Phase 2 — Requirement Analysis

## Functional Requirements

1. User can enter age.
2. User can enter height and weight.
3. System calculates BMI.
4. User can enter activity days, sleep, water and approximate calories.
5. System prepares the input features.
6. KNN model predicts a fitness focus.
7. System displays a personalized recommendation list.
8. System displays a 7-day starter plan.

## Non-Functional Requirements

- Simple and beginner-friendly UI
- Fast local execution
- Reproducible ML workflow
- No paid API dependency
- Clear educational disclaimer
- Public-repository friendly source code

## Inputs

Age, height, weight, activity days/week, sleep hours/day, water litres/day and approximate daily calories.

## Outputs

BMI, BMI category, predicted fitness focus, model confidence and personalized starter plan.

## Constraints

The project uses synthetic training data for demonstration. It is not trained on clinical or patient data and is not intended for diagnosis or treatment.
