# Phase 8 — Demo Video Script

Target length: about 3–5 minutes.

## 1. Introduction — 20 seconds
"Hello, this is Team 1 and our project is AI FitTrack. It is a simple machine-learning based fitness planning application."

## 2. Problem — 20 seconds
"Beginners may not know what fitness focus to start with. Our application takes basic profile and lifestyle inputs and gives a simple starting recommendation."

## 3. Show the Application — 60 seconds
- Open the Streamlit application.
- Enter a name.
- Enter age, height and weight.
- Select activity days, sleep and water.
- Enter approximate daily calories.
- Show the BMI value.
- Show the predicted ML goal and confidence.

## 4. Explain the AI — 60 seconds
"The model uses six numerical features: age, BMI, activity days, sleep, water and approximate calories. We standardize the features and use a K-Nearest Neighbors classifier. The output is a broad fitness focus."

## 5. Show Recommendations — 40 seconds
- Scroll to Personalized Plan.
- Explain 2–3 recommendations.
- Show the 7-Day Starter Plan.

## 6. Show GitHub — 30 seconds
- Open the public repository.
- Show README.
- Show phase folders.
- Open the development app.py file.

## 7. Closing — 20 seconds
"AI FitTrack demonstrates an end-to-end AI/ML workflow in a simple web application. Thank you."

## Recording Checklist

- [ ] Application works before recording.
- [ ] No personal passwords or private information are visible.
- [ ] Browser URL and repository are visible clearly when required.
- [ ] Explain the ML feature in simple words.
- [ ] Verify Google Drive sharing before submission.
